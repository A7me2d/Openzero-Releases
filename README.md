## Meet Open Zero

Open Zero brings AI conversations, project files, code editing, terminals and Git into one desktop app. Work with an individual agent, or build a **Super Agent** team with a central Brain and separate worker conversations.

Choose providers and models for your workflow. Give workers focused tasks, follow their progress, inspect their changes and keep the final decision in your hands.

![Super Agent office with a central Brain and connected desks](assets/super-agent.png)

## Built around your workflow

| Feature | What you can do |
| --- | --- |
| **Super Agent** | Organize a Brain and worker desks, each with its own conversation and project folder. |
| **Multiple providers** | Connect Codex, OpenCode, Cline and Claude, with FCC and Ollama integrations where configured. Availability depends on installed tools and their capabilities. |
| **Execution and review** | Assign execution, review and rapid-response roles; follow work through the task board. |
| **Core-Brain** | Connect a local knowledge repository and recall approved project notes, preferences, decisions and lessons. |
| **Mochi** | Follow connected team activity and supported assistance actions according to your settings. |
| **Editor and explorer** | Search filenames or contents, edit in tabs, use Auto Save and keep a floating conversation beside the code. |
| **Source Control** | Inspect changes, prepare commits and push through the integrated Git interface. |
| **Terminal** | Run project commands in the Windows desktop terminal. |
| **Appearance** | Choose themes, including Liquid Glass, and switch between English and Arabic. |

## Download and install

1. Open the **[latest release](https://github.com/A7me2d/Openzero-Releases/releases/latest)**.
2. Under **Assets**, download `Open-Zero-Setup-<version>.exe`.
3. Run the installer, launch Open Zero and activate it with a valid activation key.
4. Open **Settings → Connections & updates** and enable the providers you want to use.
5. Select your project and start a conversation or create a Super Agent team.

The `.blockmap` and `latest.yml` files support automatic updates; they are not installers. GitHub's **Source code** archives contain this downloads repository, not the application source.

## Requirements

- **Windows x64**.
- A valid **Open Zero activation key**. Downloading the installer does not include activation.
- Your own installed and authenticated provider tools. Model access, quotas and charges follow those providers and your accounts.
- Internet access for online providers and updates. Local model requirements depend on your configuration.

Node.js and npm are not required simply to run the packaged app. Provider tools and your projects may have their own requirements.

## Updates and compatibility

Check for updates in **Settings → Connections & updates**. This repository hosts official installers and update metadata. Older installations using the previous repository need the transition update or a manual installation of the latest version here.

Extension support is selective: installing a VS Code extension does not guarantee compatibility. Agent capabilities vary by provider, model and available tools. Review changes and test your project before accepting a result.

Core-Brain stores reviewed knowledge; an agent's report alone is not proof that code works. Connected providers may receive prompts, selected code and tool context according to your use and permissions.
